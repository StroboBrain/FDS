We can say that we get node x tasks per node = ranks. If we want to exchange messages between nodes, it only makes sense if we have 2+ nodes.
Rather we use 1 or 2 tasks per node depends on the problem we have. If we take 2 tasks per node, 
we have faster intra-node communication because rank0 and rank 1 are both on node 0 and share some memory. 
So in this case no need to communicate over the network (only when we want to exchange with rank 2 or 3).
So we could split up the costly communication to the intra-node communication and the less expensive to the inter-node communication.
